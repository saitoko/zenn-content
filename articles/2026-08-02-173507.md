**2026年8月2日週のまとめ**: Claude Code v2.1.213〜v2.1.220 の変更をまとめた。今週のハイライトは、Opus 5が新しいデフォルトのOpusモデルとして追加されたこと（v2.1.219、1Mコンテキスト対応・価格はOpus 4.8と同額）と、`/verify`・`/code-review`・`/deep-research`の自律実行が段階的に廃止されたこと（v2.1.215・v2.1.218）の2件。あわせて、権限自動承認の穴を塞ぐセキュリティ修正が複数入っており、後段の一覧でまとめて触れる。

## はじめに

今週の Claude Code 更新をまとめた。対象は v2.1.213〜v2.1.220 の変更（前回: [2026/07/18週](https://blog.saitoko.net/entry/2026/07/18/093000)）。

公式の What's New 週別ダイジェスト（`code.claude.com/docs/en/whats-new`）は2026-08-02時点でこの範囲（Week 30以降）がまだ公開されていない。そのため本記事は GitHub の `CHANGELOG.md`・GitHub Releases・npm レジストリを一次情報源としてまとめている。

なお v2.1.213 は npm レジストリには公開されているが、公式 `CHANGELOG.md`・GitHub Releases のいずれにもエントリが存在せず、何が変わったのか公式情報からは分からなかった。この点は「その他の変更一覧」に注記として載せるにとどめる。

## 今週のハイライト

### 1. Opus 5が新デフォルトのOpusモデルに（v2.1.219）

v2.1.219でClaude Opus 5が追加され、新しいデフォルトのOpusモデルになった。最大の変化はコンテキストウィンドウで、1Mトークンに対応している。価格はOpus 4.8と同額に設定されており、入力$5/出力$25 per Mtokという水準になる（Anthropic公式Pricingドキュメントおよび公式CHANGELOGで確認）。fast modeで使う場合の価格は$10/$50 per Mtokだ。

あわせてfast modeの対象モデルからOpus 4.7が除外され、以降 `/fast` はOpus 5とOpus 4.8のみに適用されるよう変更された。以前のバージョンでOpus 4.7をfast modeで使っていた場合、アップデート後は自動的に対象外になる。手元の設定やドキュメントで「fast modeはOpus 4.7」と書いている箇所があれば、書き直しておいたほうがいい。

### 2. スキルの自律実行が段階的に廃止（v2.1.215・v2.1.218）

今週は複数バージョンにわたって、Claudeが自律的にスキルを実行する挙動が縮小された。v2.1.215で`/verify`・`/code-review`の自律実行が廃止され、使う場合は明示的にコマンドを呼び出す必要がある。v2.1.218では`/deep-research`の自動起動も廃止され、同様に手動実行が前提になった。

あわせてv2.1.218で`/code-review`はバックグラウンドサブエージェントとして実行されるよう変更され、レビュー結果が会話を埋め尽くさなくなった。積み重ねたスラッシュコマンドをまとめてレビュー対象にできる点も地味に嬉しい変更だ。3件に共通するのは「Claudeが判断して勝手にやってくれる」から「明示的に呼ぶ」への揺り戻しで、自律実行の暴走を懸念していたユーザーには歓迎できる方向の変更だろう。

## セキュリティ・データロス関連の修正は見逃さないほうがいい

「その他の変更一覧」の中に、影響度「高」の項目が複数ある。ハイライトほど目立たないが、実害につながりうる内容なので触れておく。

**`dir/**`許可ルールの過剰マッチ（v2.1.214）**: `Edit(src/**)`のような単一セグメントの許可ルールが、ツリー内のどこにあっても`dir/`という名前のディレクトリへの書き込みを誤って自動承認していたバグが修正された。意図しないディレクトリへの書き込みが確認プロンプトなしで通っていた可能性があるため、細かく権限ルールを設定している場合は影響範囲を確認しておきたい。あわせて、同じ`dir/**`系のフック`if:`条件のセマンティクスも変更されており（破壊的変更）、任意の深さにマッチさせたい場合は`**/dir/**`と書き直す必要がある。

**左矢印キーによる会話破棄バグ（v2.1.218、データロス回避）**: 編集直後に左矢印キーを押すと、会話が取り消し不能な形で破棄されてしまうバグが修正された。編集直後は確認を求めるよう変更されている。作業内容が消えるタイプの不具合なので、修正前のバージョンを使っていた場合は影響がなかったか振り返っておくといい。

**サブエージェントのネスト起動デフォルトが週内で二転**: v2.1.217で「サブエージェントは自身のサブエージェントをデフォルトでは起動しない」という制限が入った直後、v2.1.219で「デフォルト深さ3までネスト可能」に戻された。CHANGELOG.mdの記載をそのまま追った限りでは矛盾ではなく事実としての方針転換だが、なぜ1週間足らずで戻したのかは公式ソースからは読み取れない。多段のサブエージェント構成を運用している場合は、現在のバージョンでの挙動を`CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH`の設定値とあわせて確認しておくのが安全だ。

なお v2.1.220 は公式CHANGELOG.mdの記載が「Bug fixes and reliability improvements」の1行のみで、具体的な変更内容は公式情報からは分からなかった。
