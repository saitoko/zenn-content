## 今週の主要変更: フックマッチャー修正・MCP認証・rewind拡張

### 1. v2.1.195: フックマッチャー修正——ハイフン入り識別子の挙動が変わる

**何が変わったか**: ハイフンを含む識別子（例: `code-reviewer`、`mcp__brave-search`）を使ったフックが、これまで誤って部分一致していた。v2.1.195 でこの問題が修正され、完全一致に変更された。

**どう使うか・注意点**: この修正は既存の設定に破壊的変更をもたらす可能性がある。たとえば `mcp__brave-search` を hook matcher に指定していた場合、修正後は完全一致として評価されるため、**複数ツールにパターンマッチさせたい場合は `mcp__brave-search__.*` のような正規表現記法への移行が必要**になる。

`settings.local.json` や `CLAUDE.md` の `hooks` セクションにハイフン入り識別子を書いている場合は、アップデート後にフックが想定どおり発火しているかどうかを確認することを勧める。静かに動かなくなるタイプの変更なので、見落としやすい。

加えて v2.1.195 では、日本語・中国語・タイ語など単語間にスペースを入れない言語での音声入力が自動送信されなかったバグも修正された。また、フルスクリーンモードのマウスクリック/ドラッグ/ホバー操作を環境変数 `CLAUDE_CODE_DISABLE_MOUSE_CLICKS` で無効化できるようになった。

### 2. v2.1.186: MCP 認証のブラウザ不要化・`!` コマンドの自動応答

**何が変わったか**: `claude mcp login` / `claude mcp logout` コマンドでブラウザを開かずに MCP の認証フローを完結できるようになった。ヘッドレス環境やリモートサーバー上での MCP 利用において、ブラウザが使えない状況での認証が現実的になる。

**`!` コマンドの挙動変化**: `!` コマンドでシェルコマンドを実行すると、その結果を受けて Claude が自動的に応答を返すようになった。シェルコマンドの実行結果を都度確認しながら会話できる流れだが、自動応答が不要な場合は `respondToBashCommands: false` の設定で無効化できる。

**その他**: `/workflows` にステータスフィルタ（実行中・完了済みで絞り込み可）、`/plugin` に Skills セクションが追加された。

### 3. v2.1.191: `/rewind` が `/clear` をまたいで使えるように・CPU 使用率 37% 削減

**何が変わったか**: これまで `/rewind`（会話の巻き戻し）は直近の `/clear` 以降の会話のみを対象としていたが、v2.1.191 からは `/clear` 実行前の会話にも遡れるよう拡張された。長いセッションで途中 `/clear` した後に「さっきの文脈に戻りたい」という場面での使い勝手が改善される。

**CPU 使用率の改善**: テキスト更新処理が 100ms 単位に統合されたことで、CPU 使用率が約 37% 削減されたとドキュメントには記載されている。長時間セッションでファンが高回転になりやすかったユーザーには体感しやすい改善かもしれない。ただし私自身は実測していないため、実際の効果については公式ドキュメントを確認してほしい。

**その他の修正**: スクロールジャンプの修正・バックグラウンドエージェントが誤って復活するバグの修正・フルスクリーンモードでリンクの Cmd+Click が機能するようになった、の3点が含まれる。
